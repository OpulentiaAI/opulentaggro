# OpulentAggro Flow Coverage Map

Maps **documented intercompany flows** in this workspace to the **OpulentAggro** implementation on Railway ERPNext, the **erpnext-mcp-server** tool layer (stdio + Vercel `/api/mcp`), and the **Vercel Next.js desk** at `/app/*`.

**Last audited:** 2026-06-08  
**Tool count:** 41 MCP tools (16 `sto_*` + 14 `ic_*` + 11 generic)  
**Coverage:** **100%** of documented AgroFresh PDF flows at OpulentAggro MVP parity

---

## Overview

OpulentAggro implements all five AgroFresh intercompany process areas: **STO**, **standalone IC billing**, **triangular sales**, **accrual allocations**, and **matching & clearing / central reconciliation**. SharePoint BOL archive is documented with Tier 2 path stub; live Graph upload remains external.

```mermaid
flowchart TB
  subgraph docs [Documented Flows]
    STO[Stock Transfers PDF]
    TRI[Triangular Sales PDF]
    ACC[Accrual Allocations PDF]

  end

  subgraph mcp [MCP Layer — 41 tools]
    STO_T[sto_* × 16]
    IC_T[ic_* × 14]
    GEN[generic × 11]
  end

  subgraph app [App Layer]
    V_UI[Vercel /app/*]
    V_API[/api/sto /api/ic /api/mcp]
    R_API[Railway whitelisted methods]
  end

  STO --> STO_T
  IC_BILL --> IC_T
  TRI --> IC_T
  ACC --> IC_T
  MC --> IC_T

  STO_T --> V_API --> R_API
  IC_T --> V_API --> R_API
  V_API --> V_UI
  R_API --> V_UI
```

| Layer | Host | Role |
|-------|------|------|
| **Railway ERPNext** | `https://erpnext-production-512a.up.railway.app` | System of record; whitelisted intercompany APIs |
| **Vercel MCP proxy** | `https://vercel-indol-phi-69.vercel.app/api/mcp` | Streamable HTTP — same 41 tools as stdio |
| **Vercel desk** | `https://vercel-indol-phi-69.vercel.app/app/*` | STO, IC billing, triangular, reconciliation |
| **AgroFresh SAP (engagement)** | S/4 OData + Workflow | Target production system |

> **Tier legend**
>
> - **Tier 1 (POC):** STO + IC billing — full MCP + UI.
> - **Tier 2 (MVP):** BOL, triangular, accrual, treasury clear — OpulentAggro equivalents implemented.
> - **External only:** SharePoint Graph BOL upload, SAP Fiori inbox, CitiConnect/HSBC bank gateways.

## STO Intercompany Flow

AgroFresh SAP-MM/SD/FI stock transfer process ([pdf-executive-summaries.md](./pdf-executive-summaries.md) §1).

### Summary table

| # | AgroFresh step | Role | SAP | OpulentAggro equivalent | MCP tool | Railway API method | Vercel UI | Status |
|---|----------------|------|-----|---------------------------|----------|-------------------|-----------|--------|
| 1 | Create & code STO | Requestor | MM | Internal Purchase Order (draft) | `sto_create` | `create_stock_transfer_order` | `/app/sto-dashboard`, `/app/purchase-order/{name}` | ✅ Full |
| 2 | Approve & post STO | Approver | MM + Workflow | DoA workflow-lite + submit | `sto_request_approval`, `sto_approve`, `sto_reject` | `request_sto_approval`, `approve_sto`, `reject_sto` | `/app/sto-trace` DoA banner + Submit | ✅ Full |
| 3 | Route to Sender | System | Workflow | Intercompany Sales Order | `sto_approve_and_route` | `approve_and_route_stock_transfer` | `/app/sto-trace` → Approve & Route | ✅ Full |
| 4 | Delivery / goods in transit (643) | Sender | MM | Delivery Note → GIT warehouse | `sto_post_goods_in_transit` | `post_goods_in_transit` | `/app/sto-trace` → Post GIT | ✅ Full |
| 5 | Auto IC invoice | System | SD | Sales Invoice + Purchase Invoice | `sto_create_ic_invoice` | `create_intercompany_invoice` | `/app/sto-trace` → Create IC Invoice | ✅ Full |
| 6 | Auto IC AR/AP settlement | Accounting | FI | Linked SI/PI submit | *(bundled in step 5)* | `create_intercompany_invoice` (`submit=1`) | Same as step 5 | ✅ Full |
| 7 | Goods receipt | Requestor | MM | Intercompany Purchase Receipt | `sto_post_goods_receipt` | `post_stock_transfer_receipt` | `/app/sto-trace` → Post GR | ✅ Full |
| 8 | Three-way match | System | FI (MIRO) | PO vs PR vs PI tolerances | `sto_three_way_match` | `run_stock_transfer_three_way_match` | `/app/sto-trace` match panel | ✅ Full |
| 9 | Match → IC match & clear | Workflow | FI | Payment Entry clearing (F110-lite) | `ic_match_and_clear` | `match_and_clear_intercompany_invoice` | Trace clearing panel + `/app/reconciliation` | ✅ Full |
| 10 | No match → dispute | Requestor + Sender | Workflow | Open/resolve dispute workflow-lite | `sto_open_dispute`, `sto_resolve_dispute` | `open_sto_dispute`, `resolve_sto_dispute` | Trace dispute panel | ✅ Full |
| 11 | Booking advice / BOL | Sender | PDF + Workflow | HTML BOL + SharePoint path stub | `sto_generate_booking_advice` | `generate_booking_advice` | Trace BOL panel + download | ✅ Full |
| 12 | Trace / list / observability | All | — | Document chain + stage inference | `sto_get_trace`, `sto_list` | `get_stock_transfer_trace`, `list_stock_transfer_orders` | `/app/sto-trace`, `/app/sto-dashboard` | ✅ Full |

### STO workflow stages

```
Draft → Pending Approval → Approved → Goods In Transit → IC Invoiced → Received → Three Way Matched → Completed
                                                                                      ↘ Dispute
```
