OpulentAggro Intercompany

STO Gateway on Vercel

HTTP gateway for the ERPNext MCP server and STO list proxy. The full OpulentAggro desk (Frappe/ERPNext + MariaDB + Redis) runs on a persistent host — not on Vercel.

Endpoints

  • GET /api/health — deployment + ERPNext connectivity
  • GET|POST|DELETE /api/mcp — MCP Streamable HTTP (stateless)
  • GET /api/sto — STO list proxy

Configure

Set ERPNEXT_URL, ERPNEXT_API_KEY, and ERPNEXT_API_SECRET in the Vercel project. Optionally set MCP_AUTH_TOKEN to require Bearer auth on /api/mcp.
